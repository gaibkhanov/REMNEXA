## Read status claims carefully

A development source push is not a stable release. Recorded test results are not a new run, a full Windows certification or a recovery guarantee. Local AI, a complete graphical dashboard, complete offline distributions and an installer remain planned. See the verification report before relying on a feature.

Examples use project-relative paths or generic application-location variables. Review logs/backups for private data before sharing them publicly.
