## Statusangaben richtig lesen

Ein Entwicklungs-Push ist kein stabiles Release. Dokumentierte Testergebnisse sind kein neuer Lauf, keine vollständige Windows-Zertifizierung und keine Wiederherstellungsgarantie. Lokale KI, vollständiges grafisches Dashboard, komplette Offline-Ausgaben und Installer bleiben geplant. Prüfe den Bericht, bevor du dich auf eine Funktion verlässt.

Beispiele verwenden projektbezogene relative Pfade oder allgemeine Variablen für Anwendungspfade. Prüfe Logs/Sicherungen vor öffentlicher Weitergabe auf private Daten.
